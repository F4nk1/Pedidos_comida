# Sistema de Gestión de Pedidos de Comida Local - Cusco
 
---
    
## 1. Descripción del Proyecto
    
Una startup local ubicada en la ciudad de Cusco busca digitalizar y optimizar la gestión de pedidos de comida tradicional y local. El objetivo es conectar a restaurantes típicos con clientes locales y turistas, garantizando una entrega eficiente y trazable.
        
---
    
## 2. Objetivos del Sistema
    
- **Gestión de Restaurantes y Menús**
- **Toma y Despacho de Pedidos** 
- **Trazabilidad y Organización**
